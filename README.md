# جدولي الأسبوعي (تطبيق يعمل بدون إنترنت)

ملفات الموقع كاملة. بياناتك بتتخزن على الجهاز اللي بتفتحه منه.

## الرفع (مجاني)
- Netlify: ادخل على app.netlify.com/drop واسحب فولدر `jadwal-pwa` كله.
- أو GitHub Pages: ارفع محتويات الفولدر في Repository وفعّل Pages من الإعدادات.
- لازم الرابط يكون https (كل الاستضافات دي بتوفره).

## التثبيت على الموبايل
- أندرويد (Chrome): من القائمة اختر Install app أو Add to Home screen.
- آيفون (Safari): زر المشاركة ثم Add to Home Screen.
افتح التطبيق مرة واحدة وإنت متصل بالنت، وبعدها يشتغل من غير نت.

## نسخة احتياطية
من زر الإعدادات داخل التطبيق: تصدير يحمّل ملف JSON، واستيراد يرجّعه أو ينقله لجهاز تاني.
على الآيفون، التطبيق المثبت له تخزين منفصل عن Safari، فاستورد نسخة احتياطية لو بدأت منه من جديد.

## التعديل
بعد أي تعديل في الملفات غيّر `VERSION` في أول ملف `sw.js` (مثلاً v2) وارفع الملفات تاني،
وبعدها الأجهزة هتحمّل النسخة الجديدة عند فتح التطبيق مرتين.

## الخطوط
الخطوط (IBM Plex Sans Arabic و Reem Kufi) بتتحمّل من Google Fonts أول مرة وإنت متصل وبتتخزن للاستخدام بدون نت.
لو فتحت التطبيق أول مرة بدون نت هيستخدم خط النظام لحد ما تتصل.
